TonyFX v0.31.0 - Private Transfer Package (AE 2023-2026)

1. Extract the ZIP to a normal folder on the other Windows PC.
2. Double-click install.cmd.
3. Open After Effects 2023, 2024, 2025, or 2026.
4. Open Window > Extensions > TonyFX.

If an older TonyFX window is already open, close that panel and reopen it after installation.

Core presets, effects, graphs, text tools, motion tools, Color Studio, and the icon browser work locally without Codex usage.

Offline captions additionally require:
- Python 3
- FFmpeg available on PATH
- faster-whisper installed in Python
- A multilingual Whisper model (the first model download can be large)

The extension remains private and is installed only under the current Windows user's Adobe CEP extensions folder.
