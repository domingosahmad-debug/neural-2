# Shared project brief

Project: UNASSIGNED — this is the studio template, not the paused production batch.
Mode: task-specific; exact replica, creative adaptation, original edit or scoped repair must be declared.
Goal: carry measured preparation from specialist stations into a preserved, editable Codex/native edit while avoiding repeated model work.

Before production fill: reference and source paths; clean song; required subject and language; target dimensions/exact rational FPS/duration; authorized scope; protected project/comps/ranges; desired typography/grade; selected example; deliverables; acceptance/review owner; allowed local tools/providers; resource and data-sharing boundaries.

Each task's TASK.json contains the current human instructions and input references. No legacy project is implicitly assigned. Collaborators: Media → Analysis + Story → Sound/Design → Editing → Independent Review/Delivery → scoped repair as needed. Codex is director and, when authorized, native editor. Any provider can fill a preparation station after capability/readiness checks; provider names are not requirements.
