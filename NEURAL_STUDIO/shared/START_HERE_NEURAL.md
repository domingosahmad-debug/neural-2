# Start here in Neural

Run `python tools/neural_cli.py start-here` from the Neural Studio folder. It reads the current project and revision, direction ID, authorization, director, pending native command and exact completion watches without inference. Then run `python tools/neural_cli.py status` for live ownership. If Neural is closed, saved records are historical evidence. Opening Neural, reading a handoff, or changing the selected profile does not assign work.

- **Director.** Use the Directors picker to select a capable profile at a safe boundary. Claude Opus, Sol and Gemini have separate durable conversations. Gemini 3.8 Flash High uses the Antigravity connection and is an explicit human choice. Selection itself starts no turn. A human direction is needed after a manual handoff. A provider refusal or stale quota report is not evidence that a new conversation will help.
- **Staff a station.** Run `python tools/neural_cli.py staffing --station analysis --capability text`, replacing the station and capabilities to match the task. Use the selected agent ID with `assign` and `dispatch`. Each worker reads its exact TASK.json, station START_HERE.md, frozen revision, skills and output contract. Home station is a display preference. Choose by the adapter's actual capabilities and verified input evidence. OpenCode uses an exact allowed free model ID. Gemini workers use Antigravity. OpenCode and ordinary Gemini station jobs receive bounded text. Actual playback, listening and AE writes require their own supported lane.
- **Use local operations first.** Probe, extract, measure and validate through `tools/local_ops.py`. Watch the exact worker, local or TonyFX job through Neural and end the turn while it runs. A terminal event is the next trigger. Never run an external chat watcher in parallel. Use one fresh Goldfish reviewer at the appropriate plan or proof checkpoint and at most one targeted recheck of a changed blocker.
- **Resolve a failure.** Read the exact receipt and distinguish a capability or allowance refusal, an interrupted process, and UNKNOWN execution. Correct a diagnosed input or route at a safe boundary before retrying. An UNKNOWN native result requires matching evidence and reconciliation. Keep one native writer and protect existing edits, source clocks, manual AE work and saved provider conversations.
- **Leave a handoff.** Record objective, project/revision, latest human decision, current owner, exact command/job/preview IDs, evidence limits, and the next permitted action. Put the update in the active project state or shared active handoff. Every director receives current authority and watch IDs in its continuation packet. Technical checks, playback, listening and Tony's approval remain separate.
