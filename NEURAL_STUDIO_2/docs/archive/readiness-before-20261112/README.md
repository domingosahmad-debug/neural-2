# Neural Studio 2

Launch Neural Studio 2 from the desktop shortcut or Launch-Neural-2.cmd. It runs as a separate native desktop window using its own packaged Electron runtime, Python companion, profile and SQLite workspace. The companion binds a free loopback port. No browser launch is used.

Tony's editing workspace is preloaded, linked to C:/Users/TUF/Documents/New project. The knowledge directory contains frozen copies of the accepted live-action workflow, reference analysis, motion, typography, audio, shot selection, review and handoff skills, plus the exact all-five acceptance records. Open Editing knowledge to see the methods and paths. Each task packet includes the workflow, skill locations, accepted evidence and approved current-revision results.

In any station, use Routing to prepare a task for any externally accessible model. Local agents can use station_cli.py projects, station_cli.py packet PROJECT_ID STATION and station_cli.py result RESULT.json. The desktop service address is discovered automatically. Chats without local tools use packet download and result import.

Director notebook saves instructions and revisions. Review opens selected local cut files, supports playback, scrubbing, version switching and persistent timecoded notes. Reselect local video files after reopening. Evidence approval is explicit.

Current limits: external handoff does not launch a provider. Direct dispatch, automatic switching, reference media analysis automation and native After Effects writes still need implementation. Native editing stays disabled while the original app owns production. Video timeline assembly is pending. Accepted knowledge is available context, not a claim that the app has independently performed artistic review.
