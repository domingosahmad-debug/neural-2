# Manual Edit workspace

Launch the desktop app with Launch-Neural-2.cmd, select a project, then open Edit beside Review. Import media with the native picker. Add a video's full source range to V1 or an audio source to Music. Select a timeline clip and adjust source in/out in seconds, then Apply. Scrub, split at the playhead, reorder with the arrow buttons, or remove a clip. Undo/redo cover timeline changes. Captions have explicit start/end and text; select a caption to edit/delete it. Caption ranges must not overlap.

Save edit persists a revision in this app's own data/editor/projects.sqlite3. Each workspace project has its own timeline. Dirty drafts are retained in memory when switching projects; save them before closing. Save refuses a stale revision rather than overwriting another writer. Imports add source registration and save the catalog; they do not copy/move source media. Imported paths, size, timestamp and SHA256 identify the source. A renamed/replaced source must be reimported and reviewed.

Export MP4 saves first, freezes the revision, and queues a CPU render. Progress and terminal status appear in Rendered exports; the saved completion inbox notifies Director. Play render verifies actual continuous output. Save video opens a native destination picker and copies the verified MP4. Export work lives under data/editor/exports/JOB_ID: timeline.json, job.json, per-step logs, probe.json and output.mp4. Interrupted exports are reported on next launch, never replayed. Two codec threads/one filter thread, low priority; own assistant gate and media lock protect against overlap inside Neural2. Original Neural/AE is unchanged and has a separate scheduler.

The v1 timeline is sequential video cuts plus source audio, one music track and manually timed captions, up to 1920 per dimension and 24/25/30/60 fps. Source preview uses desktop codecs and can pause at source switches; render is continuous. H264 MP4/AAC is recommended for live preview. Unsupported preview codecs produce an error; no proxy generation is claimed. See EDITOR_PLAN.md for timing/fit/audio/caption render semantics. Mixing does not auto-duck or normalize; keep gains low enough to avoid clipping.

Not implemented: multiple video layers, native effect plugins, transitions, motion/keyframe/BlurMoCurves editing, automatic captions, advanced compositing, AI-directed timeline execution or AE project conversion. Existing accepted-motion knowledge is retained in Editing knowledge but is not an implemented effects engine. This is a working cut editor, not a replacement for the full After Effects workflow yet.

Evidence: EDITOR_PROOF.json (real FFmpeg mixed-aspect/rate cut, 60 frames, caption pixel interval, audio frequency components, source fingerprint mutation, stale save/invalid trim); EDITOR_DESKTOP_PROOF.json (real desktop controls, persistence, playback, export and byte ranges); EDITOR_ADMISSION_PROOF.json (simulated work through actual admission code in both enqueue orders, interrupted recovery). Native import dialog and successful import were observed separately. Human listening, broad codec coverage, long-form render performance and artistic acceptance remain untested.
