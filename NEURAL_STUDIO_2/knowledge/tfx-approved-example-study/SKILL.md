# Approved example study

Read `../../../docs/APPROVED_EXAMPLES.md`, then inspect only the example closest to the current brief and its adjacent lesson/evidence files.

1. Separate durable principles from project-specific choices. Story clarity, motivated transitions, editable structure, verified text, and character separation transfer broadly. A palette, font, exact graph, timing, or outro logo transfers only when the current brief supports it.
2. Compare the target reference and source footage against the chosen approved example. Explain which behaviors should carry over and which must change.
3. Prefer the user's native AE effect stack and manual adjustment evidence over reconstructing a look from a flattened screenshot.
4. Use approved examples as acceptance evidence only when the user explicitly approved that exact revision. Do not treat filenames or technical validation as approval.
5. Keep the new work original: reproduce the level of intention and polish, not the finished example's footage or exact design.
