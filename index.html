04 / Routing

Seats, notsubscriptions.

Every seat is a provider, a model and an effort level from model_catalog.json. For each station you pick an ordered list. When a seat is unavailable, out of quota or failing, the gateway moves to the next one.

  • Hand-offs happen only at safe boundaries, never in the middle of an After Effects command.
  • No paid fallback. Neural never switches you to a paid API or changes billing.
  • Workers wait on real completion events with station_cli.py wait, so nothing burns tokens polling.

06 / Rules

The rules thatkeep it honest.

Distilled from the source studio's operating policy. Your own brief and corrections always override the creative defaults, but these seven are never broken.

  1. 01

    One native AE writer

    Only the lease holder sends TonyFX commands. Never two AE instances, never a second bridge.

  2. 02

    Never replay an UNKNOWN

    If it is unclear whether a command ran, inspect AE first.

  3. 03

    Never delete locks by hand

    Not while a run is live. Use Debug → maintenance.

  4. 04

    Manual Edit is human-only

    The AIs never act in your station.

  5. 05

    No billing or provider changes

    No paid fallback. OpenCode seats stay on free models unless you say otherwise.

  6. 06

    Never print or commit secrets

    Service tokens, cookies and CLI credentials stay on your machine.

  7. 07

    Report AE crashes at once

    A crash or hang goes straight to the human.

  8. ∞

    Only the human accepts

    Tests, sampled pixels, full-speed playback and listening are separate gates. Acceptance is yours.
